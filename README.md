# ASANA Dosya Yöneticisi

Türkçe, reklamsız ve ücretsiz Android dosya yöneticisi.

v0.1: Android Storage Access Framework (SAF) ile kullanıcı tarafından seçilen klasörleri görüntüler, alt klasörlere girer ve dosyaları güvenli görüntüleme intent'iyle açar. Dosyaları silmez veya değiştirmez.

GitHub Actions > Android APK > Artifacts alanından debug APK indirilebilir. Android 8.0+ gerektirir.

Gizlilik: Reklam, takip SDK'sı ve INTERNET izni bulunmaz. Seçilen klasör izni Android tarafından yönetilir.
